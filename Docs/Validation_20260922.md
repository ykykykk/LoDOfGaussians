# YKPC 训练验证记录 — 2026-09-22

## 环境与范围

本轮代码、测试、真实数据短训练均在 YKPC 执行：Windows、RTX 3090 24 GB、64 GB RAM、项目 Python 3.10、PyTorch 2.14.0+cu126，MSVC 14.44。测试期间其他 GPU 应用保持运行，结果不是隔离硬件的标准基准。

数据包含 43 张标定照片，42 张训练、1 张留出。原图 6004×4010，速度和细化探针使用 3002×2005。原生 CUDA 后端严格加载成功。

回归结果：119 passed、0 failed、0 skipped，覆盖 CPU 与真实 CUDA 的 gsplat 前向/梯度、偏心主点投影、索引 Adam、跨视角预取、Adam Graph、状态写回、增量 SPT、评分单位、分裂预算、Windows 独立进程导入等。首次运行触发编译；最终使用已有编译缓存的测试耗时 6.51 秒。

GPU 验证定位并修复了 Adam Graph 捕获时冻结掩码的生命周期，以及本地化 MSVC 输出的解码问题。Windows 数据加载进程的相机导入环也已修复。

## 速度对照

两组使用同一 6000 步粗训练模型、同一照片分辨率、种子和点集；细训练预算 300 步，测试阶段关闭分裂，只比较图像输入与常驻容量策略。原实现计数包含 iteration 0，实际执行 301 次前后向。

| 指标 | 4-worker、1 GiB 分散图像缓存 | 共享完整 CPU 图像缓存、按实际点数分配池 |
|---|---:|---:|
| 预热后 100→290 步墙钟平均 | 194.70 ms/步 | 59.36 ms/步 |
| 包含启动、首次解码和收尾的细训练耗时 | 71.85 秒 | 35.26 秒 |
| 抽样取图等待中位数 | 120.80 ms | 0.089 ms |
| PyTorch 峰值 allocated | 3129.58 MiB | 1076.34 MiB |
| 初始常驻槽位 | 8000000 | 282223 |
| 最终导出叶节点 | 58344 | 58344 |

预热段约 3.28 倍，包含启动的本次短任务约 2.04 倍。峰值 allocated 不是整机显存占用。不能将短测试倍数直接外推到所有场景、完整训练或更多点数。

同一留出视角的叶节点 PLY 渲染：参考 PSNR 26.03095 dB、SSIM 0.846834；输入优化组 26.02923 dB、0.846822。两次训练并非逐像素完全相同，平均像素绝对差约 8.84e-5，最大局部差约 0.219，因而不能宣称逐位等价。

## 细化与导出验证

1000 步真实数据探针从同一粗训练模型开始，采用归一化最大梯度阈值 0.001、每窗至多 15% 叶节点的合格候选预算。为在短测试中覆盖多个树修改边界，分裂设置为第 200、400、600 步，并在最后阶段停止分裂；这不是默认正式训练的日程。

| 分裂步数 | 可见叶节点 | 超过阈值叶节点 | 实际分裂父节点 | 分裂后叶节点 |
|---|---:|---:|---:|---:|
| 200 | 56962 | 12856 | 8752 | 67096 |
| 400 | 66816 | 17295 | 10065 | 77161 |
| 600 | 77131 | 17976 | 11575 | 88736 |

初始 58344 个叶节点，结束导出 88736 个，完整 hierarchy 为 277471 个总节点。探针 profile 最终墙钟 85.63 秒，PyTorch 峰值 allocated 1102.85 MiB。实际分裂数未超过合格候选，保存和最高细节叶节点导出成功。

同一留出视角：1000 步探针 PSNR 26.62268 dB、SSIM 0.860644；用户已有 20000 步结果为 27.17712 dB、0.871859。训练预算不同，这不能证明新策略最终画质胜过已有完整结果；新增节点必须继续优化。单留出视角也不足以代替多场景、多视角验收。
